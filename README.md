# 🎓 Error Book System - AI智能错题本

一个基于 AI 的数学作业批改和错题管理系统。学生通过微信小程序拍照上传作业，系统自动识别答案、对比标准答案进行批改，并将错题自动收集进错题本。根据艾宾浩斯遗忘曲线科学安排复习提醒。

## ✨ 核心功能

### 🎯 学生端
- **作业拍照上传** - 通过微信小程序拍照上传作业
- **智能批改** - AI自动识别答案并与标准答案对比
- **详细解析** - AI生成的详细解析帮助学生理解
- **错题本管理** - 自动收集错题，按时间和分类管理
- **智能提醒** - 基于艾宾浩斯遗忘曲线的复习提醒
  - 第1天：立即显示解析
  - 第3天：提醒复习
  - 第7天：再次提醒
  - 第14天：强化复习
  - 第30天：最后巩固
- **进度追踪** - 查看错题掌握度和学习统计

### 👨‍🏫 老师端
- **题库管理** - 上传标准答案和解析
- **批改管理** - 审核AI批改结果
- **班级统计** - 查看班级整体学习情况
- **学生分析** - 逐个学生的学习进度和高频错题
- **报告导出** - 生成学生学习报告
